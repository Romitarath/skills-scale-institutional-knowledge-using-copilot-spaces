# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents. It includes a short summary of our approach and direct links to each document in the docs/ folder to make processes easier to find and reference.

Project management processes (brief)
- Customer-first, iterative delivery with clear ownership (PM + PdM).
- Lifecycle: Initiation → Planning → Execution → Release → Retrospective.
- Regular rhythms: daily standups, weekly delivery syncs, sprint demos, and PM+PdM weekly alignment.
- Key artifacts: project one-pager, backlog, Definition of Done, risk register, release notes, retrospective actions.
- Workflows: project board columns (Backlog → Ready → In Progress → In Review → QA → Done), small PRs with acceptance criteria, CI checks, and required reviews.
